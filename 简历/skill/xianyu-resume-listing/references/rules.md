# 闲鱼简历项目专项规则

本文件只服务于“职场简历优化/制作”项目，不是公开商品详情页，不替代闲鱼最新协议或App内规则。

## 一、官方规则入口

1. [闲鱼社区卖家服务协议](https://terms.alicdn.com/legal-agreement/terms/platform_service/20220929192826912/20220929192826912.html)
2. [闲鱼社区用户服务协议](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_other/suit_bu1_other201708081618_51146.html)
3. 发布前核对闲鱼App内“闲鱼公约”、发布页面提示、服务类目要求和审核结果。

平台可能根据商品、交易、账号和风险信号综合判断并采取删除信息、限制账号或停止服务等措施。因此本规则只能降低风险，不能保证不扣分、限流或封号。

## 二、发布前检查

### 必须确认

- [ ] 这是职场简历服务，不是PPT或其他项目
- [ ] 个人公司、职位、年限和能力描述真实
- [ ] 标题与详情页描述同一项服务
- [ ] 价格或价格档位已确定
- [ ] 预计交付时间已确定
- [ ] 修改次数和修改范围已确定
- [ ] 交付格式已确定
- [ ] 是否包含英文、岗位描述匹配和版式调整已确定
- [ ] 商品类目和发布页面实际允许的服务形式已确认

### 信息不完整时

只输出“待补充草稿”和缺失字段，不输出可直接发布的最终稿。

## 三、公开文案检查

### 必须写清

- 服务对象：职场跳槽、转行、晋升或岗位匹配
- 服务内容：经历梳理、项目改写、成果提炼、岗位匹配、版式调整
- 交付物：Word、PDF或实际可提供的文件
- 预计时效
- 修改轮次
- 超出范围的处理方式

### 不得写

- 保证面试、保证Offer、保证录用
- 百分百通过、领导必选、薪资翻倍
- 虚构大厂、HR、负责人、猎头或内推身份
- 虚构客户、订单、评价、成功案例和项目数据
- 站外联系方式、二维码、外部链接或隐晦引流暗号
- 复制同行标题、图片、详情页、Logo或客户简历

### 公开文案与内部规则隔离

- 不把本文件的检查表、风险词清单和审核说明直接放入商品详情。
- 商品详情只保留买家需要了解的服务范围、交付边界和资料说明。
- 内部检查可以提及风险词，但公开商品图和详情页不得使用这些词作为营销话术。

## 四、接单前确认

首轮沟通至少确认：

- 目标岗位
- 使用场景
- 现有简历是否完整
- 需要重点优化的部分
- 是否有岗位描述
- 交付格式
- 期望时间
- 修改次数

客户只需先提供脱敏片段和完成评估所需的信息，不要求完整身份证明、住址、账户信息或无关隐私。

## 五、服务范围控制

### 基础范围

- 简历结构梳理
- 工作经历润色
- 项目经历改写
- 成果和业务价值提炼
- 岗位关键词匹配
- 自我介绍或职业概述优化
- 版式调整

### 需要单独确认的增项

- 大量新增经历或从零重写
- 英文翻译或英文重写
- 多个岗位版本
- 求职信、自我介绍长文或其他求职材料
- 超出约定的多轮修改
- 重新设计完全不同的版式

### 不承诺

- 面试、录用、薪资、晋升或跳槽结果
- 背调证明、学历证明、工作证明或其他真实性文件
- 代投、代聊、内推或绕过平台完成交易

## 六、交付与售后

- 交付时间从资料齐全且订单约定确认后开始计算。
- 客户迟交资料，交付时间顺延。
- 客户新增岗位方向、大量新增内容或改变原需求，先确认是否增项。
- 修改只覆盖订单约定范围和轮次。
- 交付格式必须与商品页和订单约定一致。
- 退款、争议和售后遵守闲鱼平台规则及订单约定。
- 保留必要的沟通、报价、约定和交付记录。

## 七、统一HTML输出协议

- 用户未指定其他格式时，默认交付 `output/*.html` 单文件。
- HTML 前 6 页为 3:4 竖版商品图，顺序固定为：封面定位、客户痛点或前后对比、服务内容与能力、适用场景、制作流程、交付说明。
- HTML 后半部分固定包含：推荐标题、可复制详情页、自动回复、待补充字段和上架自检。
- 简历与 PPT 只共享页面结构和交付方式，服务文案、案例和交付物不得混用。
- 生成后检查页面数量、商品图顺序、教育/校园词、站外导流词、结果承诺词、AI相关词、隐私词和项目串用。

## 八、最终自检

- [ ] 没有教育、校园或学生场景词
- [ ] 没有相关技术营销词
- [ ] 没有站外导流内容
- [ ] 没有结果保证
- [ ] 没有虚构身份和数据
- [ ] 没有未经授权的案例和素材
- [ ] 服务范围、价格、时效、修改和交付一致
- [ ] 没有把内部规则复制到公开详情页
