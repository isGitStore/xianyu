# 闲鱼PPT项目规则

## 项目范围

本目录只管理职场PPT定制服务，不管理简历、作品集或其他求职材料。

适用场景：

- 工作汇报
- 述职竞聘
- 项目复盘
- 年度总结
- 客户提案
- 商业展示

## 服务定位

默认定位：

> 工作汇报PPT定制｜述职竞聘｜项目复盘｜年度总结｜商业展示

个人背书必须来自真实经历。可以使用以下匿名模板，但只有经历真实时才能发布：

> 曾任某头部互联网公司产品负责人，拥有多年产品与项目管理经验，熟悉工作汇报、项目复盘和业务展示的内容结构与表达方式。

## 商品内容

- 默认通过单文件 HTML 制作6张3:4竖版商品图，呈现方式与 `简历/` 项目保持一致。
- 商品图固定顺序：封面定位、客户痛点或页面前后对比、服务内容与能力、适用场景、制作流程、交付说明。
- HTML 的 6 张商品图页面放在前面，详情页文案放在后面，便于逐页截图和复制到闲鱼。
- 详情页必须写清PPT类型、适用场景、预计页数、交付格式、修改次数和交付时间。
- 默认交付PPTX可编辑版和PDF预览版；只有在实际可以提供时才这样写。
- 是否包含图表重绘、数据核对、演讲稿、演讲排练和多轮修改，必须提前写清楚。

## 内容边界

- 只能承诺制作范围和文件交付，不承诺晋升、竞聘成功、融资成功、汇报通过或客户签约。
- 不虚构公司、职位、客户、项目数据、案例数量或商业成果。
- 商业计划、客户提案和工作汇报材料必须确认客户有权提供，并完成必要脱敏。
- 图片、字体、图标、模板、Logo和案例必须自有、原创、已授权或可合法使用。
- 商品内容只写PPT服务，不自动带入简历岗位关键词、Word简历交付或简历修改规则。

## 执行入口

- Skill：`skill/xianyu-ppt-listing/SKILL.md`
- 专项规则：`skill/xianyu-ppt-listing/references/rules.md`
- 产出目录：`output/`

## 默认输出模式

- 用户未指定格式时，必须生成 `output/*.html`，不能只给 Markdown。
- 文件命名默认使用 `output/<主题>_闲鱼上架稿.html`。
- HTML 后半部分必须包含：推荐标题、详情页正文、自动回复、待补充字段和上架前自检。
- 没有确认的个人经历、案例、价格、页数、时效、修改次数和文件格式，必须使用占位符并标为待补充。
- PPT 项目只写职场 PPT 服务，不把简历的 Word 交付、岗位关键词或简历服务文案带入页面。
