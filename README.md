# 闲鱼服务上架素材库

这个仓库用于整理闲鱼虚拟服务商品的上架素材、项目规则、Skill 说明和可复制的成品稿。当前包含两个独立项目：`PPT/` 和 `简历/`。

两个项目共享同一套输出方式：默认生成单文件 HTML。HTML 前 6 页是 3:4 竖版商品图，适合逐页截图上传到闲鱼；后半部分放推荐标题、详情页正文、自动回复、待补充字段和上架前自检。

## 项目列表

### PPT

目录：`PPT/`

用途：制作职场 PPT 定制服务的闲鱼上架内容，适用于工作汇报、述职竞聘、项目复盘、年度总结、客户提案和商业展示。

主要产物：

- `PPT/output/工作汇报PPT定制_闲鱼上架稿.html`：可打开截图的完整 HTML 上架稿。
- `PPT/output/ppt竞品拆解与上架稿.md`：竞品标题拆解、商品图结构和详情页文案草稿。
- `PPT/skill/xianyu-ppt-listing/SKILL.md`：PPT 项目的执行规则。
- `PPT/skill/xianyu-ppt-listing/references/rules.md`：PPT 上架核查规则。

### 简历

目录：`简历/`

用途：制作职场简历优化服务的闲鱼上架内容，适用于跳槽、转行、晋升、岗位匹配、工作经历润色和项目经历改写。

主要产物：

- `简历/output/简历优化_闲鱼上架稿.html`：可打开截图的完整 HTML 上架稿。
- `简历/output/简历优化_闲鱼上架稿.md`：简历服务详情页和商品图文案草稿。
- `简历/output/闲鱼合规上架检查清单.md`：发布前检查清单。
- `简历/skill/xianyu-resume-listing/SKILL.md`：简历项目的执行规则。
- `简历/skill/xianyu-resume-listing/references/rules.md`：简历上架核查规则。

## 使用方式

1. 先看根目录 `AGENTS.md`，确认通用规则。
2. 进入具体项目目录，例如 `PPT/` 或 `简历/`。
3. 查看该项目的 `AGENTS.md` 和 `skill/.../SKILL.md`。
4. 打开 `output/*.html`，前 6 页逐页截图作为闲鱼商品图。
5. 复制 HTML 后半部分的标题、详情页正文和自动回复到闲鱼。
6. 发布前补齐价格、页数、交付时间、修改次数、真实经历和案例授权情况。

## 输出规范

所有新上架稿默认按 HTML 输出，结构固定：

1. 封面定位
2. 客户痛点或前后对比
3. 服务内容与能力
4. 适用场景
5. 制作流程
6. 交付说明
7. 推荐标题
8. 详情页正文
9. 自动回复
10. 待补充字段
11. 上架前自检

项目之间只共享页面结构，不共享具体文案、案例和交付承诺。PPT 项目只写职场 PPT 服务，简历项目只写职场简历服务。

## 合规原则

- 不虚构公司、职位、年限、客户、案例、数据、订单量、评价或服务结果。
- 不承诺保证面试、Offer、晋升、竞聘成功、融资成功、汇报通过或客户签约。
- 不放外部联系方式、二维码、外部链接或隐晦导流暗号。
- 不复制同行商品图、详情页、文案或第三方商业模板。
- 使用图片、字体、图标、模板和案例前，确认自有、原创、已授权或可合法使用。
- 客户资料按最小必要原则收集，涉及内部资料、客户信息和商业数据时先脱敏并确认使用权。
